# Design Spec: PDF Metadata & Title/Author Deep Sanitizer (`/tools/metadata-pdf`)

## 1. Problem Statement & Motivation
PDF documents generated by software like Microsoft Word, Adobe InDesign, Google Docs, scanner software, and LaTeX silently embed extensive forensic and privacy-compromising metadata. This often includes:
- Author names and company user accounts
- Computer hostnames, operating systems, and file paths
- Creation and modification timestamps down to the second
- Software producer/creator signatures and version numbers
- Embedded XML Metadata Packets (XMP streams) containing editing histories and UUIDs

Legal teams submitting exhibits, whistleblowers, journalists, academic researchers submitting blind peer-reviewed papers, and privacy-conscious users must sanitize or adjust this information. Commercial tools (Adobe Acrobat Pro, Sejda) put this behind \$15–\$30/mo paywalls. Free online tools upload confidential PDFs to remote servers.

AirPDF provides a **100% Client-Side, In-Browser PDF Metadata & Deep Sanitizer** that operates entirely in memory with zero file uploads and zero rasterization.

## 2. Architecture & Capabilities

### Core Engine (`src/lib/pdf/metadata.ts`)
1. **Metadata Reader (`readPdfMetadata`)**:
   - Extracts standard Info dictionary entries:
     - `title`
     - `author`
     - `subject`
     - `keywords` (array or delimited string)
     - `producer`
     - `creator`
     - `creationDate` (Date or ISO string)
     - `modificationDate` (Date or ISO string)
   - Checks presence of XMP stream in `doc.catalog.get(PDFName.of('Metadata'))`.
2. **Metadata Updater & Sanitizer (`updatePdfMetadata`)**:
   - **Mode A: Custom Editing**: Updates or replaces chosen fields while preserving page structure and vector content.
   - **Mode B: Deep Sanitization (Anonymize)**:
     - Wipes `title`, `author`, `subject`, `keywords`, `producer`, `creator`.
     - Clears or zeroes `creationDate` and `modificationDate`.
     - Strips and deletes the `/Metadata` catalog entry (XMP packet) completely:
       `srcDoc.catalog.delete(PDFName.of('Metadata'))`.
     - Ensures `/PieceInfo`, `/ID`, and related document metadata tracking dictionaries are scrubbed if present.
3. **Zero Content Disturbance**:
   - Preserves all pages, vector fonts, forms, and document streams without re-compressing or touching page content.

## 3. UI/UX Interface (`src/components/tools/MetadataPdfIsland.astro`)
1. **Dropzone**: Drag & drop PDF file.
2. **Inspection & Editor Panel**:
   - Displays all extracted metadata tags clearly with status badges ("Detected" vs "Empty").
   - Quick Action: **"One-Click Deep Sanitize (Wipe All Identifiers)"** button for instant anonymization.
   - Manual editing inputs for Title, Author, Subject, Keywords, Producer, and Creator.
   - Timestamp options: "Keep Timestamps", "Update to Current Time", or "Completely Strip Timestamps".
3. **Execution & Feedback**:
   - Real-time diff summary showing before & after states.
   - Instant vector download with sanitized filename (`document-sanitized.pdf`).
