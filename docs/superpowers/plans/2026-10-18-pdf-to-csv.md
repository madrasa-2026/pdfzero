# Implementation Plan: In-Browser PDF to CSV / Table Extractor (`/tools/pdf-to-csv`)

## Phase 1: Core Engine (`src/lib/pdf/tableExtractor.ts`)
- Define `TableTextItem`, `TableRow`, `TableGrid`, `ExtractorOptions`, and `TableExtractionResult`.
- Implement `clusterRows(items: TableTextItem[], yTolerance: number): TableRow[]`.
- Implement `detectColumnBounds(rows: TableRow[], minGap: number): number[]`.
- Implement `formatRowsToGrid(rows: TableRow[], columnBounds: number[]): string[][]`.
- Implement `serializeGridToCsv(grid: string[][]): string`.
- Implement `extractTablesFromPdf(pdfBytes: Uint8Array, options?: ExtractorOptions): Promise<TableExtractionResult>`.

## Phase 2: Unit Testing (`tests/pdf/tableExtractor.test.ts`)
- Test 1: Row clustering groups items with close vertical baselines.
- Test 2: Column detection splits items separated by horizontal gaps.
- Test 3: RFC 4180 CSV serialization properly escapes quotes and commas.
- Test 4: End-to-end table extraction from a synthetic multi-column PDF table.

## Phase 3: Content Collection & UI Island
- Create `src/content/tools/pdf-to-csv.md` (`category: 'convert'`, `icon: 'table'`).
- Build `src/components/tools/PdfToCsvIsland.astro` (Dropzone, live table preview with row/col count, CSV download button, Copy to Clipboard button, options for delimiter & page range).
- Wire router in `src/pages/tools/[slug].astro` and Footer link in `src/components/layout/Footer.astro`.
