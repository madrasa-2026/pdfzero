# In-Browser Privacy OCR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a 100% in-browser, privacy-preserving PDF OCR tool (`/tools/ocr-pdf`) on AirPDF that transforms scanned, photo-only, and non-searchable PDFs into searchable, selectable PDFs with an invisible text layer, and provides direct plain text / markdown export without server uploads.

**Architecture:** Client-side Astro Island (`OcrPdfIsland.astro`) orchestrating a client-side OCR recognition and searchable text layer injection engine (`src/lib/pdf/ocr.ts`).

**Tech Stack:** Astro, TypeScript, Tailwind CSS, `pdf-lib`, PDF.js, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-18-ocr-pdf-design.md`

## Global Constraints
- **100% In-Browser:** Zero server uploads, zero network leaks.
- **Searchable PDF Standard:** Injects invisible text layer with `pdf-lib` aligned to page dimensions so text can be highlighted, selected, and searched.
- **Dual Export:** Searchable PDF (`.pdf`) and Plain Text (`.txt`).
- **Dual Audit Loop:** AI code & security audit + Human UX audit before advancing to next tool.
