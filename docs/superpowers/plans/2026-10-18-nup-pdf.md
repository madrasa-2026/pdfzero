# Implementation Plan: PDF N-Up Multi-Page Imposer (`/tools/nup-pdf`)

## Phase 1: Engine Implementation (`src/lib/pdf/nup.ts`)
- Define `NupLayout = '2-up' | '4-up' | '6-up' | '8-up' | '9-up' | '16-up'`.
- Define `SheetSize = 'a4' | 'letter' | 'legal' | 'a3' | 'source'`.
- Define `SheetOrientation = 'auto' | 'portrait' | 'landscape'`.
- Define `NupOrder = 'horizontal' | 'vertical'`.
- Define `NupOptions` interface with layout, sheetSize, orientation, order, margin, spacing, drawBorders, drawCutMarks, and pageRange.
- Implement grid resolution helper `getGridDimensions(layout: NupLayout, isLandscape: boolean): { rows: number; cols: number }`.
- Implement sheet dimension resolver `resolveSheetDimensions(size: SheetSize, orientation: SheetOrientation, srcWidth: number, srcHeight: number, rows: number, cols: number): { width: number; height: number }`.
- Implement page parser `parsePageRange(rangeStr: string, totalPages: number): number[]`.
- Implement core function `imposeNup(pdfBytes: Uint8Array, options?: NupOptions): Promise<NupResult>`.

## Phase 2: Unit Testing (`tests/pdf/nup.test.ts`)
